# Aplicação e Avaliação de um Sistema Adaptativo Baseado em Lógica Fuzzy para o Ensino de Robótica com Arduino

---

## 📄 Descrição Geral do Artigo

Este repositório reúne os **artefatos computacionais e educacionais** associados ao estudo **“Aplicação e Avaliação de um Sistema Adaptativo Baseado em Lógica Fuzzy para o Ensino de Robótica com Arduino”**.

O trabalho apresenta o **desenho, implementação e avaliação** de um sistema adaptativo que utiliza **lógica fuzzy** para personalizar trilhas de aprendizagem em um curso de Robótica com Arduino, direcionando os estudantes para **conteúdos regulares, de reforço ou de desafio**, conforme seu desempenho.

---

## 🎯 Objetivo do Recurso Educacional

O recurso educacional tem como objetivo:

* Apoiar o ensino de **Robótica Educacional**
* Demonstrar o uso de **Inteligência Artificial simbólica (lógica fuzzy)** aplicada à educação
* Promover **personalização da aprendizagem** em contextos educacionais reais
* Servir como **artefato replicável** para pesquisas em sistemas adaptativos

---

## 🧠 Fundamentos Teóricos

O sistema está fundamentado em:

* Sistemas Adaptativos de Aprendizagem
* Lógica Fuzzy aplicada à educação
* Zona de Desenvolvimento Proximal (Vygotsky)
* Avaliação formativa e trilhas personalizadas
* Dimensões cognitiva, metacognitiva e afetiva da aprendizagem

Esses fundamentos são discutidos e referenciados no corpo do estudo.

---

## 🏗️ Arquitetura do Sistema

O sistema é composto por três camadas principais:

1. **Interface do Usuário (HTML)**

   * Diagnóstico inicial
   * Conteúdos didáticos
   * Quizzes avaliativos

2. **Camada de Processamento (Google Apps Script)**

   * Correção automática das avaliações
   * Inferência fuzzy
   * Decisão da trilha de aprendizagem

3. **Camada de Dados (Google Sheets)**

   * Armazenamento das respostas
   * Registro de desempenho
   * Histórico da adaptação

Todo o sistema é executado no ecossistema do **Google Workspace**, sem dependências externas.
