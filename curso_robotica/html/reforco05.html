🔁 Reforço 05 – Revisando o Sensor Ultrassônico

✨ Só mais um passo! O sensor ultrassônico é um dos recursos mais legais do seu robô. Ele permite que o robô “enxergue” sem usar câmera, apenas medindo a distância até os obstáculos. Se algo estiver muito perto, ele pode parar, desviar ou emitir um alerta. Vamos revisar?

📌 Pontos principais

  • O sensor HC-SR04 envia um som que rebate no obstáculo e volta.
  • O tempo entre enviar (TRIG) e receber (ECHO) o som é usado para calcular a distância.
  • Podemos usar esse valor no código para acender um LED, parar um motor ou emitir um som.

Exemplo de condição no código:

if (distancia < 20) {
  // faz algo, como parar o robô
}
