🔊 Tópico 03 – Usando o Buzzer e Botões: Som e Interação com o Robô

📚 O que vamos aprender nesta aula?

Neste tópico, vamos trazer interatividade sonora para o seu robô! Você vai aprender a emitir sons com um buzzer e a usar botões para controlar ações no circuito. Primeiro faremos a simulação no Tinkercad, depois montaremos tudo fisicamente com o Arduino. Essa prática abre caminho para alarmes, toques personalizados e comandos via botão.

🔉 Conhecendo os componentes

🎵 O que é o buzzer?
O buzzer é um pequeno alto-falante usado para gerar sons simples. Existem dois tipos:

  • Buzzer passivo: precisa de sinais PWM variáveis para tocar sons diferentes.
  • Buzzer ativo: emite um som fixo ao receber corrente. É o que usaremos aqui.

Atenção: o buzzer ativo já tem um oscilador interno — basta aplicar 5V para que ele apite.

🖲️ O que é um botão (push button)?
O botão é um dispositivo de entrada digital. Quando pressionado, ele fecha o circuito, permitindo a passagem da corrente.

🛠️ Etapa 1 – Montando no Tinkercad

  1. Acesse o site: https://www.tinkercad.com
  2. Clique em “Criar novo circuito”.
  3. Adicione: 1× Protoboard, 1× Buzzer (ativo), 1× Push button, 1× Resistor 10kΩ, 1× Arduino UNO e fios.
  4. Esquema:
    • Buzzer: “+” no pino 8, “–” no GND.
    • Botão: um lado no pino 2; outro no +5V.
    • Resistor 10kΩ: entre GND e o pino do botão (pull-down).

🧾 Código em C++

int buzzer = 8;
int botao  = 2;

void setup() {
  pinMode(buzzer, OUTPUT);
  pinMode(botao, INPUT); // usando resistor externo de 10kΩ como pull-down
}

void loop() {
  if (digitalRead(botao) == HIGH) {
    digitalWrite(buzzer, HIGH); // Toca o som
  } else {
    digitalWrite(buzzer, LOW);  // Silêncio
  }
}

🔁 Etapa 2 – Copiando o código para o Arduino físico

  1. No Tinkercad, “Código” → “Texto”.
  2. Copie e cole no Arduino IDE.
  3. Monte o circuito físico igual ao simulado.
  4. Envie o código para o Arduino.
