⚙️ Tópico 04 – Simulando e Controlando Motores com Ponte H (L298N)

📚 O que vamos aprender nesta aula?

Agora chegou a hora de colocar seu robô em movimento! Nesta aula, você aprenderá a controlar um motor DC (corrente contínua) usando a Ponte H L298N, que permite fazer o motor girar para frente, para trás ou parar — como nos carrinhos de controle remoto!

A prática será feita primeiro no Tinkercad, com simulação do circuito, e depois com os componentes físicos, conectando o motor real ao Arduino. O controle de atuadores (como motores) é um dos pilares da robótica educacional, por permitir que os projetos deixem de ser apenas sinais visuais ou sonoros e passem a ter movimento real.

🚗 Por que usar uma Ponte H?

A Ponte H é um circuito especial que permite inverter o sentido da corrente elétrica que passa pelo motor. Isso possibilita controlar a rotação do motor:

  • 🟢 Girar para frente
  • 🔄 Girar para trás
  • ⛔ Parar

O módulo L298N já vem pronto com esse circuito, facilitando a ligação com o Arduino, e pode ser usado para motores DC ou motores de passo.

🛠️ Etapa 1 – Montando no Tinkercad

  1. Acesse: https://www.tinkercad.com
  2. Clique em “Criar novo circuito”.
  3. Adicione:
    • 1× Arduino UNO
    • 1× Módulo Ponte H L298N
    • 1× Motor DC
    • 1× Fonte externa (ex.: bateria 9V simulada)
    • Fios de conexão
  4. Conexões:
    • IN1 (Ponte H) → pino 8 do Arduino
    • IN2 (Ponte H) → pino 9 do Arduino
    • ENA → pino 10 do Arduino (ou +5V se não usar PWM)
    • OUT1/OUT2 → fios do motor DC
    • GND da Ponte H → GND do Arduino
    • VCC da Ponte H → alimentação externa (9V/12V)

🧾 Código em C++

int IN1 = 8;
int IN2 = 9;
int ENA = 10;

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
}

void loop() {
  // Gira para frente
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(ENA, HIGH);
  delay(2000);

  // Para
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  delay(1000);

  // Gira para trás
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(ENA, HIGH);
  delay(2000);

  // Para
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  delay(1000);
}

➡️ Clique em “Iniciar Simulação”: o motor deve girar para frente, parar, girar para trás e parar novamente. Com isso, você já compreende a lógica de controle direcional de motores DC, essencial para robôs móveis!

🔁 Etapa 2 – Copiando o código para o Arduino físico

  1. No Tinkercad, clique em “Código”.
  2. Troque de “Blocos” para “Texto”.
  3. Copie o código (Ctrl+C) e cole no Arduino IDE (Ctrl+V).
  4. Monte o circuito real (ponte H + motor DC).
  5. Conecte o Arduino via USB e clique em “Enviar”.

⚠️ Dicas importantes

  • 🟠 Use fonte externa para alimentar o motor (9–12V). O Arduino não fornece corrente suficiente.
  • 🟡 Conecte todos os GNDs juntos (Arduino + fonte + Ponte H).
  • 🔵 Se o motor não girar, confira pinos, inverta OUT1/OUT2 e verifique o jumper de habilitação do ENA (se não usar PWM).
