📡 Tópico 05 – Sensor Ultrassônico e Lógica de Parada Automática

📚 O que vamos aprender nesta aula?

Nesta etapa do curso, você vai aprender a usar o sensor ultrassônico HC-SR04 para detectar obstáculos à frente do robô e programar uma ação de parada automática. Esse tipo de funcionalidade é amplamente utilizada em robôs autônomos, sistemas de estacionamento inteligente e veículos com direção assistida.

Vamos iniciar a prática no Tinkercad e, em seguida, realizar a montagem física com Arduino e o sensor real. A robótica com sensores estimula o desenvolvimento de habilidades como resolução de problemas, lógica condicional e raciocínio computacional aplicado.

🔊 Como funciona o sensor ultrassônico?

O HC-SR04 emite ondas sonoras de alta frequência (ultrassom). Quando essas ondas atingem um objeto, parte do som retorna ao sensor. Com base no tempo entre envio e retorno, o Arduino calcula a distância até o obstáculo.

Principais pinos:

PinoFunção
VCCAlimentação (5V)
GNDTerra
TRIGEnvia o sinal ultrassônico
ECHORecebe o sinal refletido

🛠️ Etapa 1 – Montando no Tinkercad

  1. Acesse: https://www.tinkercad.com
  2. Clique em “Criar novo circuito”.
  3. Adicione:
    • 1× Arduino UNO
    • 1× Sensor ultrassônico HC-SR04
    • 1× LED
    • 1× Resistor de 220 Ω
    • Fios de conexão
  4. Faça a ligação:
    • VCC (sensor) → 5V do Arduino
    • GND (sensor) → GND do Arduino
    • TRIG → pino digital 9
    • ECHO → pino digital 10
    • LED positivo → pino digital 13
    • LED negativo → resistor → GND

🧾 Código em C++

#define TRIG 9
#define ECHO 10
#define LED 13

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  long duration = pulseIn(ECHO, HIGH);
  float distance = duration * 0.034 / 2;

  if (distance < 20) {
    digitalWrite(LED, HIGH); // obstáculo detectado
  } else {
    digitalWrite(LED, LOW);  // área livre
  }

  delay(100);
}

➡️ Clique em “Iniciar Simulação”: aproxime objetos simulados ao sensor. O LED acenderá automaticamente se detectar algo a menos de 20 cm. Isso simula o funcionamento de um sistema de parada automática por detecção, comum em robôs e veículos inteligentes.

🔁 Etapa 2 – Copiando o código para o Arduino físico

  1. No Tinkercad, clique em “Código”.
  2. Selecione “Texto”.
  3. Copie o código (Ctrl+C) e cole no Arduino IDE (Ctrl+V).
  4. Monte o circuito com os componentes físicos:
    • HC-SR04 nos pinos 9 (TRIG) e 10 (ECHO);
    • LED no pino 13 com resistor;
  5. Conecte o Arduino ao computador via USB e clique em “Enviar”.

🧰 Se algo der errado...

  • Verifique se TRIG e ECHO estão nos pinos corretos.
  • Certifique-se de que os fios estão firmes.
  • Teste aproximar a mão ou objetos opacos (espelhos e superfícies muito lisas podem dar erro).
  • Mantenha um delay(100) para reduzir leituras falsas/ruído.
