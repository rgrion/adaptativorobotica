🧩 Tópico 02 – Montando o Primeiro Circuito com LED

💡 O que vamos aprender nesta aula?

Chegou a hora de colocar a mão na massa! Neste tópico, você dará os primeiros passos na montagem de circuitos, começando com um experimento clássico: fazer um LED piscar com o Arduino. Vamos usar o Tinkercad para simular e, em seguida, transferir o código para o Arduino físico, montando tudo com os componentes reais.

Você aprenderá:

  • A identificar e conectar os componentes;
  • A montar circuitos simples com segurança;
  • A programar o Arduino com blocos e código textual;
  • A transferir o programa do simulador para o mundo real.

Essa prática é fundamental para compreender como hardware e software se integram na robótica educacional.

🔌 Conhecendo os componentes

  • LED (Diodo Emissor de Luz): Acende ao receber corrente. Tem polaridade (lado positivo e negativo).
  • Resistor (220 ohms): Limita a corrente elétrica, evitando que o LED queime.
  • Protoboard: Placa para montagem de circuitos, sem necessidade de solda.
  • Fios jumpers: Conectam os componentes entre si.
  • Arduino UNO: Placa controladora que envia os comandos ao circuito.
  • Cabo USB: Serve para alimentar e programar o Arduino.
  • Arduino IDE: Programa no computador usado para escrever e enviar o código.

🔎 Dica: sempre use um resistor com o LED para proteger o circuito.

🛠️ Etapa 1 – Montando no Tinkercad

  1. Acesse o site: https://www.tinkercad.com
  2. Clique em “Criar novo circuito”
  3. Adicione os seguintes componentes:
    • 1x Protoboard (meia placa)
    • 1x LED
    • 1x Resistor de 220 ohms
    • 1x Arduino UNO
    • 2x Fios de conexão
  4. Monte conforme o esquema:
    Pino 13 do Arduino → lado positivo do LED
    Lado negativo do LED → resistor de 220 ohms → GND (terra) do Arduino

🧾 Código em C++

void setup() {
  pinMode(13, OUTPUT); // define pino 13 como saída
}

void loop() {
  digitalWrite(13, HIGH); // liga o LED
  delay(1000);            // espera 1 segundo
  digitalWrite(13, LOW);  // desliga o LED
  delay(1000);            // espera 1 segundo
}

🧩 Código com blocos

  • “Definir pino 13 como saída”
  • “Ligar pino 13”
  • “Esperar 1 segundo”
  • “Desligar pino 13”
  • “Esperar 1 segundo”

➡️ Clique em “Iniciar Simulação”: você verá o LED piscar a cada segundo.

🔁 Etapa 2 – Copiando o código para o Arduino físico

  1. No Tinkercad, clique em “Código”
  2. Troque de “Blocos” para “Texto”
  3. Copie o código (Ctrl+C)
  4. Abra o Arduino IDE
  5. Cole o código (Ctrl+V)
  6. Conecte o Arduino ao computador com o cabo USB
  7. Monte o circuito físico igual ao da simulação
  8. Clique em “Enviar” no Arduino IDE → O LED piscará de verdade! 🎉

🧰 Se algo der errado...

  • O lado maior do LED deve estar conectado ao pino 13 (positivo).
  • O resistor deve estar em série com o LED, indo até o GND.
  • Os fios precisam estar bem conectados.
  • Verifique a porta/placa correta no Arduino IDE.
